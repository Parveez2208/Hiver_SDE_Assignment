# 2. Reviewer Evaluation README (README_REVIEWER_EVALUATION.md)

## 2.1 Overview
The Reviewer Evaluation Model acts as a secondary, meta-evaluation layer (using a higher-capacity LLM). It ingests the evaluation results generated by the Primary Evaluation Harness via HTTP/JSON requests, validates the primary evaluator's scoring integrity, and detects potential false positives/negatives in classification and escalation decisions[cite: 1].

## 2.2 System Architecture & Data Flow
**Flow:** Primary Eval Results (JSON) -> via HTTP/REST POST -> Reviewer Evaluation Model (Large LLM) -> Unified Integrity Report (JSON)[cite: 1].

## 2.3 Core Components
**2.3.1 Reviewer Logic & Payload Parsing**
* Ingests the output JSON payload from the Primary Evaluation Harness via an HTTP API request[cite: 1].
* Translates incoming payload dictionaries into structured prompts for the Reviewer Model[cite: 1].
* Validates whether the primary evaluator correctly flagged missing keywords, misclassified intents, or improper escalation rationales[cite: 1].

**2.3.2 Verification Criteria**
* **Primary Evaluator Consistency:** Verifies if evaluation scoring matches defined grading rules[cite: 1].
* **Escalation Reason Audit:** Inspects extracted reasons behind `Escalate: <reason>` outputs to ensure semantic accuracy[cite: 1].
* **Hallucination & Grounding Check:** Scans generated support replies against ground-truth context[cite: 1].

## 2.4 Setup & Execution
**2.4.1 Prerequisites**
* Python 3.9+[cite: 1]
* Required packages: `requests`, `fastapi`, `uvicorn`[cite: 1]

**2.4.2 Running the Reviewer Evaluation Endpoint & Process**
To execute the secondary reviewer audit, use a two-terminal setup.

Start the HTTP listener in Terminal 1 (Listens on port 8000):
`python src/reviewer_service.py --port 8000`

Post evaluation results to the reviewer pipeline in Terminal 2:
`python src/send_for_review.py --eval_file ./data/primary_eval.json --endpoint http://127.0.0.1:8000/audit`

## 2.5 Output Report Structure
The secondary reviewer returns a unified evaluation report (`final_audit_report.json`) containing[cite: 1]:
* **Audit Score:** Percentage of primary evaluation decisions validated as correct (`audit_status`)[cite: 1].
* **Discrepancy Log:** Detailed list of items where the primary evaluator misjudged model responses (`discrepancies_found`, `discrepancy_details`)[cite: 1].
* **Final Approval Status:** `APPROVED` or `REQUIRES_REVISION` (`reviewer_notes`)[cite: 1].
